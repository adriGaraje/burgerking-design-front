## Código

<CodeTabs html={html} css={scss} />

| Variable     | Qué es                                                                       |
| ------------ | ---------------------------------------------------------------------------- |
| `id`         | Prefijo de los ids del acordeón. Solo cambia si hay dos FAQ en una página.   |
| `title`      | Titular de la sección (`h2`).                                                |
| `subtitle`   | Entradilla. Vacía, no se pinta.                                              |
| `items`      | Preguntas `{ question, answer }`, en orden y en cualquier número.            |
| `singleOpen` | Una sola abierta a la vez (`data-parent`).                                   |
| `firstOpen`  | La primera arranca abierta (`show` + `aria-expanded="true"`).                |
| `showCta`    | Botón «Ir a preguntas frecuentes» bajo la lista (`ctaLabel`, `ctaHref`).     |
